# 🎧 聽華語．拼台羅（Similar sounds Mandarin）

教師在大螢幕投影，即時用**注音符號**組合華語的聲母、介音、韻母、聲調並播放華語音；學生聽音後練習拼出相同組合的**台語羅馬字**，教師再依序公布「聲母 → 韻母 → 聲調 → 台語羅馬字」，並可播放台語音。介面與操作完全比照〈[聽韓語．拼台羅](https://cyril-mingdao.github.io/Similar-sounds/)〉〈[聽日語．拼台羅](https://cyril-mingdao.github.io/Similar-sounds-JP/)〉〈[聽越語．拼台羅](https://cyril-mingdao.github.io/Similar-sounds-VN/)〉。

## 頁面

| 檔案 | 用途 |
|---|---|
| `index.html` | 投影頁（上課用） |
| `review.html` | 聲調審聽頁（教師審聽、修正拼音與聲調） |

## 操作

- 左側點聲母、韻母（介音預設「無」、聲調預設一聲）→ 自動播放華語音
  - 華語沒有的組合會說明原因，例如「ㄅㄧㄤ」不成音、「ㄅㄧㄣ」沒有二聲
  - ㄓㄔㄕㄖㄗㄘㄙ 可單獨成音：介音、韻母都選「無」
- 舞臺上的注音可點，另開教育部《[重編國語辭典修訂本](https://dict.revised.moe.edu.tw/search.jsp?md=1&word=%E3%84%85%E3%84%9A&qMd=0&qCol=1)》以注音查詢這個音的字；下方顯示錄音用的例字
- 華語聲調與臺語聲調的對應：一聲 → 第 1 調、二聲 → 第 5 調、三聲 → 第 3 調、四聲 → 第 2 調
- 牌卡右上角 🔊 播單音：聲母念注音名稱（ㄅㄛ、ㄉㄜ、ㄐㄧ、ㄓ），介音、韻母單念，聲調念 ㄇㄚ 的四個調（媽、麻、馬、罵）；標題旁 ▶ 依序輪播整列，速度鈕切換 0.5～1.75 倍
- 點「聲母」「韻母」「聲調」「台語羅馬字」卡片可個別公布；公布後點台語羅馬字播放台語音
- 公布後點「聲母」「韻母」卡，播放詹宗龍老師自行錄製的聲母、韻母音檔（與〈羅馬字拼音互動遊戲〉同一批，`audio_spell/`）
- 簡報筆 ▶：聲母 → 韻母 → 聲調 → 答案 → 播台語音 → 隨機下一題；◀ 倒退
- 隨機出題採洗牌制：題庫每題各出一次，全部輪過才重新洗牌
- 快捷鍵：空白 播放｜S 慢速｜Enter 依序公布｜A 全部公布｜R 隨機｜T 倒數｜Esc 清空

## 題庫

只收華語與台語羅馬字**近似度 100%** 及教師審聽確認的音節（聲母 無・ㄅ・ㄆ・ㄇ・ㄉ・ㄊ・ㄋ・ㄍ・ㄎ・ㄏ・ㄐ・ㄑ・ㄒ・ㄗ・ㄘ・ㄙ；韻 ㄚ・ㄞ・ㄠ・ㄢ・ㄤ・ㄧ・ㄧㄚ・ㄧㄠ・ㄧㄢ・ㄧㄣ・ㄧㄤ・ㄧㄥ・ㄨ・ㄨㄚ・ㄨㄞ・ㄨㄢ・ㄨㄤ），其餘組合（ㄈ、捲舌音、ㄩ、ㄜ、ㄡ、ㄣ、ㄥ、ㄦ 等）顯示「無近似音」並說明原因。

華語音節全部預錄（Big5 常用字的讀音，不含輕聲）。

## 重新產生

```powershell
# 1. 華語音節與例字（需 pypinyin、wordfreq；結果存在 syllables.json，平常不必重跑）
.venv\Scripts\python "05羅馬字\華語拼讀投影_v1\make_syllables.py" <套件目錄>
# 2. 錄音、檢查例字聲調、台語音、data.js
.venv\Scripts\python "05羅馬字\華語拼讀投影_v1\build.py"
```

例字讀音依 pypinyin（大陸讀音），台灣讀音不同的字（如「微」台灣念 ㄨㄟˊ）由 build.py 以音高檢查聲調，對不上就換下一個例字重錄；實際使用的例字記在 `chars.json`。

## 素材來源

- 華語音檔：Microsoft Edge 語音合成（zh-TW-HsiaoChenNeural，台灣華語）念例字，起音淡入並統一音量
- 台語音檔（`audio_tw/`）：部分取自教育部《[臺灣台語常用詞辭典](https://sutian.moe.edu.tw/)》同音讀單字詞條的音檔（著作權屬教育部，依[創用CC 姓名標示－禁止改作 3.0 臺灣](https://creativecommons.org/licenses/by-nd/3.0/tw/)授權條款以原檔使用，未經剪輯或改作），其餘由陽明交大台語 TTS（男聲、台北腔）產生
- 注音查詢連結：教育部《重編國語辭典修訂本》
- 台語羅馬字依教育部《臺灣台語羅馬字拼音方案》
